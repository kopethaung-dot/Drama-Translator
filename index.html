ဗီဒီယိုကနေ မြန်မာစာတန်းထိုး SRT ထုတ်မယ်

ဗီဒီယို / အသံဖိုင် (သို့) SRT ဖိုင် ထည့်လိုက်ရင် မြန်မာ စာတန်းထိုး (.srt / .vtt) ထုတ်ပေးပါတယ်။ Google Gemini AI နဲ့ ဘာသာပြန်ပေးပါတယ်။

သိမ်းထားတဲ့ ပရောဂျက် ရှိပါတယ် — ။ အဲဒီကနေ ဆက်လုပ်မလား?

၁ — ဖိုင်ရွေးပါ

နှိပ်ပြီး ဖိုင်ရွေးပါ (သို့) ဒီမှာ ဆွဲချလိုက်ပါ
mp4, webm, mov, mp3, wav စတဲ့ ဗီဒီယို / အသံဖိုင် အားလုံး ရပါတယ်
နှိပ်ပြီး .srt / .vtt ဖိုင်ရွေးပါ (သို့) ဒီမှာ ဆွဲချလိုက်ပါ
ရှိပြီးသား စာတန်းကို မြန်မာပြန်ဆိုပေးမယ် — အချိန်တွေ ဒီအတိုင်း ထားမယ်
YouTube / TikTok link တွေ ရပါတယ် — TikTok က watermark မပါဘူး။ Red Note (小红书) က Cobalt မထောက်ပံ့သေးလို့ မရသေးဘူး။
Cobalt instance / PC bridge ကိုယ်တိုင် သတ်မှတ်မယ် (မရရင်)
အလုပ်ဖြစ်တဲ့ Cobalt instance တွေကို cobalt.directory မှာ ကြည့်လို့ရတယ် (Turnstile မပါတဲ့ instance ကို ရွေးပါ)။ PC bridge (bridge.py) ကနေ tool ကို ဖွင့်ထားရင် bridge ကို အလိုအလျောက် သုံးမယ် — URL ရိုက်စရာမလိုဘူး။

၂ — ဆက်တင်များ

ဒီကွက်မှာ ရိုက်ထားရင် အပေါ်က ရွေးထားတာထက် ဒါကို အရင်သုံးမယ်။
Gemini က အသံနားထောင်ပြီး ဘာသာပြန်တယ် — quota အများဆုံး သုံးတယ်။ Groq Whisper / Scribe က အသံပဲ နားထောင်ပြီး၊ Gemini က စာသားပဲ ပြန်တယ် — Gemini quota သက်သာတယ်။
Key မရှိရင် Groq Console မှာ အခမဲ့ ထုတ်ပါ (ကတ်မလို)။ Key ကို ဒီ browser မှာ မှတ်ထားမယ်။ Whisper large-v3 သုံးတယ် — တစ်နေ့ကို အသံ ၈ နာရီစာ အခမဲ့။
Scribe က TTS tab ထဲက ElevenLabs API Key ကို သုံးမယ် — key အသစ် မလိုဘူး။ တစ်လ ၂၇၀ မိနစ်စာ အခမဲ့၊ ပြီးရင် တစ်နာရီ $0.22။
Key မရှိရင် Deepgram Console မှာ အကောင့်ဖွင့်ပြီး API Key ထုတ်ပါ — $200 credit အခမဲ့ (ကတ်မလို)၊ ကုန်သွားရင် တစ်မိနစ် $0.0043။ Key ကို ဒီ browser မှာ မှတ်ထားမယ်။
Key မရှိရင် AssemblyAI မှာ အကောင့်ဖွင့်ပြီး API Key ထုတ်ပါ — $50 credit အခမဲ့ (ကတ်မလို)၊ ကုန်သွားရင် တစ်နာရီ $0.15။ Key ကို ဒီ browser မှာ မှတ်ထားမယ်။
Key မရှိရင် Gladia မှာ အကောင့်ဖွင့်ပြီး API Key ထုတ်ပါ — €50 credit အခမဲ့ (ကတ်မလို၊ အသံ နာရီ ၃၀၀ လောက်)၊ ကုန်သွားရင် တစ်နာရီ 0.16€။ ၁၀၀+ ဘာသာစကား၊ စာလုံးအချိန်မှတ် ပါတယ်။ Key ကို ဒီ browser မှာ မှတ်ထားမယ်။
Token မရှိရင် Hugging Face မှာ အကောင့်ဖွင့်ပြီး token အခမဲ့ ဖန်တီးပါ (Inference Providers permission ပါအောင်) — တစ်နေ့ request ~၁,၀၀၀ အခမဲ့၊ ကတ်မလို။ Groq နဲ့ မော်ဒယ်အတူတူ (Whisper large-v3)။ လူများရင် နှေးတတ်တယ် / model loading စောင့်ရတတ်တယ်။
🌐 အပြင်က transcript tool တွေနဲ့ နားထောင်မယ်
အပေါ်က Engine တွေနဲ့ အဆင်မပြေရင် အပြင်မှာ transcribe လုပ်ပြီး SRT ဖိုင် ထုတ်ပါ — ပြီးရင် ဒီ tool မှာ SRT ဖိုင်ကို ပြန်ဆိုလို့ရတယ်။
  • CapCut — Text → Auto captions (တရုတ်) → SRT ထုတ်။ SRT ထုတ်တာက Pro လိုတယ်; အခမဲ့နည်းက exportsrt.com မှာ CapCut draft ဖိုင်ကနေ ထုတ်ပါ။ CapCut ဖွင့်မယ်
  • TurboScribe — ဖိုင်တင် → SRT ဒေါင်း။ အခမဲ့ တစ်နေ့ ၃ ဖိုင်၊ တစ်ဖိုင် မိနစ် ၃၀ ထိ။ TurboScribe ဖွင့်မယ်
  • YouTube Studio — ဗီဒီယို unlisted တင် → auto captions ရပြီး Subtitles → ⋮ → Download → .srt (ကိုယ့်ဗီဒီယိုပဲ ရတယ်)။ YouTube Studio ဖွင့်မယ်
  • Whisper Web — browser ထဲမှာ Whisper run တယ်၊ key မလို၊ အသံ တင်စရာမလို (PC Chrome အကောင်းဆုံး၊ ဖုန်းမှာ နှေးတယ်)။ Whisper Web ဖွင့်မယ်
SRT ဖိုင် ရရင်: အပေါ်က “SRT ဖိုင်ကို ပြန်ဆိုမယ်” ခလုတ် နှိပ် → SRT ဖိုင် ရွေး → စတင်မယ် → ပြီးရင် ဗီဒီယို ရွေးပြီး burn လုပ်လို့ရတယ်။
အဆင့်မြင့် ဆက်တင်များ (Pacing၊ batch၊ fallback)
Request တွေကြား စောင့်ချိန် — ၇ စက္ကန့်ဆို 429 (limit) ထိတာ အများကြီး လျော့တယ်။ 0 = မစောင့်ဘူး။
ဘာသာပြန်ပြီးသား စာတန်းတွေကို မှတ်ထားပြီး ပျက်လို့ ပြန်လုပ်ရင် မပို့တော့ဘူး၊ စာသားတူတာကို တစ်ခါပဲ ပို့တယ်။ Model၊ ပုံစံ box၊ Glossary ပြောင်းရင် အလိုအလျောက် အသစ်ပြန်ဘာသာပြန်မယ်။
Key မရှိရင် Google AI Studio မှာ အခမဲ့ ထုတ်ပါ။ Key ကို ဒီ browser မှာ မှတ်ထားမယ် — browser ပိတ်ပြီး ပြန်ဖွင့်လည်း ကျန်နေမယ်။ ဖျက်ချင်ရင် အကွက်ထဲက စာကို ဖျက်လိုက်ပါ။
Gemini မုဒ်မှာ အကြောင်းအရာကို Google server သို့ ပို့ရတယ်။ 429 ထိရင် အလိုအလျောက် စောင့်ပြီး ပြန်ကြိုးစားပေးမယ်။
ဘာသာပြန်ပုံစံ (Style) နဲ့ နာမည်မှတ်တမ်း (Glossary) — မလိုရင် ကျော်ပါ
ဒီစာကို Gemini ဘာသာပြန်တိုင်း ထည့်ပေးမယ်၊ ဒီ browser မှာ မှတ်ထားမယ်။ ပြင်ဆင်ရေးထဲမှာ ပြင်ခဲ့တဲ့ စာတန်းတွေကို မူရင်း၊ စက်ပြန်၊ သင်ပြင်တာ အတွဲလိုက် ထုတ်ပေးတာက နမူနာအသစ်တွေ ရေးဖို့ အသုံးဝင်တယ်။
ဒီနာမည်တွေကို ဘာသာပြန်တိုင်း ဒီပုံစံအတိုင်းပဲ သုံးမယ် — အပိုင်းများတဲ့ ဇာတ်လမ်းမှာ နာမည် မလွဲအောင်။ "အလိုအလျောက် ထုတ်မယ်" က Gemini + Key လိုတယ်။
အပိုင်းများစွာ တန်းစီ (Batch)
အပိုင်းတွေ အများကြီး တစ်ခါတည်း ထည့်လို့ရပါတယ်
တစ်ပိုင်းပြီးမှ နောက်တစ်ပိုင်း အလိုအလျောက် ဆက်လုပ်မယ်
အပေါ်က ဆက်တင်တွေကို အပိုင်းအားလုံးအတွက် သုံးမယ်။ လုပ်နေတုန်း tab မပိတ်ပါနဲ့၊ screen ဖွင့်ထားပါ။

ပြင်စရာစာတန်း မရှိသေးပါဘူး — ဘာသာပြန် tab မှာ အရင် ဘာသာပြန်ပါ၊ ဒါမှမဟုတ် Projects tab က ပရောဂျက် ဖွင့်ပါ။

ပြီးပါပြီ — စာတန်းတွေ အဆင်သင့်ဖြစ်ပါပြီ

ဗီဒီယို ဖွင့်ရင် စာတန်းတွေ အပေါ်မှာ တက်ပြမယ်။
စာတန်းအချိန် လွဲနေရင် ညှိရန် (Sync)
စက္ကန့်
စာတန်း စောနေရင် + ထည့်ပါ (ဥပမာ +0.5 — စာတန်း နောက်ကျသွားမယ်)၊ နောက်ကျနေရင် − ထည့်ပါ။ ပြန်ဆုတ်ချင်ရင် အောက်က ↩ ပြန်ဆုတ်မယ် ကို နှိပ်ပါ။
Gemini က အချိန်ခန့်မှန်းတာ အပိုင်းလိုက် လွဲနေရင် — အသံထဲက စကားတကယ်ပြောတဲ့နေရာကို ရှာပြီး စာတန်းတစ်ကြောင်းချင်းစီရဲ့ အစ/အဆုံးကို ကပ်ပေးတယ်။ ဗီဒီယိုဖိုင် လိုပါတယ်။ မကြိုက်ရင် ↩ ပြန်ဆုတ်မယ် နဲ့ ပြန်ယူလို့ရတယ်။
တိကျအောင် ညှိချင်ရင် — စာတန်းအစပိုင်းက တစ်ကြောင်း၊ အဆုံးပိုင်းက တစ်ကြောင်း ရွေးပါ။ စာတန်းအမှတ်ကို ထည့်ပြီး ဗီဒီယိုကို အဲဒီစကားပြောတဲ့နေရာကို ရွှေ့ကာ ⏱ ကိုနှိပ်ပါ။ ညှိမယ်ကို နှိပ်ရင် စာတန်းအားလုံးရဲ့ အချိန်ကို အချိုးကျ ပြန်တွက်ပေးမယ်။

စာတန်းထိုးပြီး ဗီဒီယို ထုတ်မယ်

စာတန်းကို ဗီဒီယိုထဲ တိုက်ရိုက် ထည့်ပြီး ဖိုင်အသစ် ထုတ်မယ်။ ချိန်လိုက်တာနဲ့ အစမ်းပြမှာ ချက်ချင်း ပြောင်းပြမယ်။
နံပါတ်က ဗီဒီယိုအမြင့် 1080 px အပေါ် အခြေခံတဲ့ ဖောင့်ဆိုဒ်ပါ (ဥပမာ 24 = သေးသေး၊ 39 = ပုံမှန်၊ 60 = ကြီး)။ ဒသမ ရိုက်လို့ရတယ် (ဥပမာ 0.5)။ 0 ထည့်ရင် စာတန်း လုံးဝ မမြင်ရတော့ဘူး။ ဗီဒီယိုအရွယ်ကွာရင်လည်း အချိုးကျ ပြောင်းပေးမယ်။
စာသားအနားမှာ ဘောင်လိုင်း ထည့်ပေးတာ — ဗီဒီယိုအလင်းရောင်ပေါ်မှာပါ စာဖတ်ရလွယ်သွားမယ်။ 0 = ပိတ်ထား၊ 2–4 px = အကြံပြုထားတဲ့ အထူ။

🔊 Movie Recap မြန်မာအသံထုတ် (TTS)

Recap စာသား (script) ကို ဒီမှာ paste လုပ်ပြီး မြန်မာအသံဖိုင် (WAV) ထုတ်ပါ။
Key ကို ဒီ browser မှာ မှတ်ထားမယ် — browser ပိတ်ပြီး ပြန်ဖွင့်လည်း ကျန်နေမယ်။ ဖျက်ချင်ရင် အကွက်ထဲက စာကို ဖျက်လိုက်ပါ။ Request တစ်ခုချင်းကြား စောင့်ချိန်ကို ဘာသာပြန် tab ထဲက Gemini "Pacing" နဲ့ တူတူ သုံးမယ် (မူလ ၇ စက္ကန့်)။ မော်ဒယ် မရရင် (404 / 429 / 503) တခြား TTS မော်ဒယ်ကို အလိုအလျောက် ပြောင်းပေးမယ် ("မော်ဒယ် အလိုအလျောက် ပြောင်းမယ်" ကို ဖွင့်ထားရင်)။
Key ကို ElevenLabs မှာ ထုတ်ပါ။ Key ကို ဒီ browser မှာ မှတ်ထားမယ် — browser ပိတ်ပြီး ပြန်ဖွင့်လည်း ကျန်နေမယ်။ ဖျက်ချင်ရင် အကွက်ထဲက စာကို ဖျက်လိုက်ပါ။ မြန်မာစာကို Eleven v4 နဲ့ပဲ ဖတ်နိုင်တယ် (v3 က မြန်မာစာ မဖတ်နိုင်လို့ ဖြုတ်ထားတယ်)။ Free plan မှာ ကိုယ့်အကောင့်ထဲ ရှိပြီးသား Voice တွေပဲ API နဲ့ သုံးလို့ရတယ် (Library voice တွေက အခကြေးငွေ plan လိုတယ်)။ Voice ID ရိုက်ထည့်ထားရင် အပေါ်က ရွေးထားတာထက် ဒါကို အရင်သုံးမယ်။
Microsoft Edge ရဲ့ Read Aloud မြန်မာအသံ (Thiha / Nilar) — API Key မလို၊ အခမဲ့၊ limit မရှိ။ စာသားကို Microsoft server သို့ ပို့ရတယ်။ Microsoft က version အဟောင်းကို ပိတ်တတ်လို့ version အသစ်တွေ အလိုအလျောက် စမ်းပေးမယ်။ မရရင် စက်နာရီ (အချိန်) မှန်မမှန်နဲ့ အင်တာနက်ကို စစ်ပါ။
Microsoft AzureAzure Portal မှာ Speech resource (F0 — အခမဲ့, တစ်လ စာလုံး 500,000) ဖွင့်ပြီး Keys and Endpoint က Key + Region ကို ကူးထည့်ပါ။ Key ကို ဒီ browser မှာ မှတ်ထားမယ်။ Azure account ဖွင့်ဖို့ ကတ် လိုတယ် (အခမဲ့အတွက်တောင်)။ တစ်ကြောင်း စာလုံး 2,000 အထိ ရတယ်။
ပျက်သွားရင် (429 စတာ) "အသံထုတ်မယ်" ကို ပြန်နှိပ်ပါ — ထုတ်ပြီးသား အပိုင်းတွေ ပြန်မထုတ်တော့ဘူး။ စာသား၊ အသံ၊ Engine၊ လေသံ တစ်ခုခု ပြောင်းရင်တော့ အသစ်ပြန်ထုတ်မယ်။

🎬 Movie Recap — Dubbing လုပ်မယ်

ဗီဒီယို ထည့် → transcript → မြန်မာပြန် → Thiha / Nilar အသံနဲ့ TTS → မူရင်းအသံ တိုးတိုးလေးထားပြီး မြန်မာအသံ အပေါ်က တင် (dubbing) → မြန်မာစာတန်းထိုးပါ ပါတဲ့ MP4 ထုတ် — အားလုံး ဒီ tab တစ်ခုတည်းမှာ။ ဗီဒီယိုက အပေါ်မှာ ပုံသေကပ်နေမယ်၊ အောက်ကဟာတွေပဲ ရွေ့မယ်။
Engine / ဘာသာစကား ရွေးတာက ဘာသာပြန် tab နဲ့ တစ်ထပ်တည်း ဖြစ်မယ် — ဒီမှာ ပြောင်းရင် အဲဒီမှာလည်း ပြောင်းသွားမယ်။ Key တွေကို ဒီ tab ထဲက အောက်က အကွက်မှာ ထည့်လို့ရတယ် — တခြား tab ကို သွားစရာ မလိုဘူး။

Edge အခမဲ့ အသံ — Key မလို။ Azure ရွေးရင် Key + Region ကို TTS tab ထဲမှာ ထည့်ထားရမယ်။ Gemini / ElevenLabs ရွေးရင် TTS tab ထဲက အသံနဲ့ Key ကို သုံးမယ်။
အလိုအလျောက်ခွဲရင် ကန့်သတ်ထက်ရှည်တဲ့ စာတန်းတွေကို "။" "၊" နဲ့ space ကျတဲ့နေရာမှာ ဖြတ်ပြီး အချိန်ကို စာလုံးအရေအတွက်အလိုက် ခွဲပေးတယ်။ ခွဲပြီးရင် Dub အသံ အဟောင်းက မသုံးတော့ဘူး — နောက် Dub ခလုတ် (နားထောင်မယ် / တွဲကြည့်မယ် / MP4 ထုတ်မယ်) နှိပ်ရင် အသစ်နဲ့ အလိုအလျောက် ပြန်ရောပေးမယ်။
ဗီဒီယိုထဲမှာ ကပ်ပါလာတဲ့ တရုတ်စာတန်း / လိုဂိုကို ဖုံးမယ် — Video tab burn box နဲ့ တစ်ထပ်တည်း ဖြစ်မယ်။ မြန်မာစာတန်းက blur အပေါ်မှာ ကြည်ကြည်လင်လင် ပေါ်မယ်။
ပိတ်ထားရင် မြန်မာအသံပဲ ကြားရမယ်။ MC စကားပြောခန်းလို မူရင်းအသံ ထားချင်တဲ့ စာကြောင်းကို အောက်က စာရင်းထဲက 🔊 ခလုတ် နှိပ်ပါ — အဲဒီစာကြောင်းမှာ မူရင်းအသံ အတိုင်း ကြားရမယ်၊ TTS မထုတ်ဘူး။
TTS ကို ပုံမှန်အတိုင်း ထုတ်ထားပြီး ဒီမှာပဲ အမြန်နှုန်း တင်လို့ရတယ် — အသံပြန်ထုတ်စရာ မလိုဘူး။ အမြန်နှုန်း တင်လေ စာကြောင်းတွေ slot ထဲ ဝင်လေ၊ dub ဗီဒီယိုနဲ့ ကိုက်လေ။ ဒါပေမယ့် အသံ မြန်သွားသလို အသံလည်း တက်သွားမယ် (2X / 2.5X ဆို တော်တော် မြန်သွားမယ်)။ ပြောင်းပြီးရင် Dub အသံကို အသစ်နဲ့ ပြန်ရောပေးမယ်။
တရုတ်စာတန်း တိုတိုကို မြန်မာလို ပြန်ဆိုရင် စာရှည်သွားပြီး အသံက ဗီဒီယိုထက် ရှည်တတ်တယ် — အဲဒီအခါ MP4 ထုတ်တဲ့အခါ ဗီဒီယိုကုန်တဲ့နေရာကနေ နောက်ဆုံးပုံကို ရပ်ထားပြီး ဖြည်းဖြည်း zoom ဆွဲပြီး အသံကုန်တဲ့အထိ ဆက်ထုတ်ပေးမယ်။ ပိတ်ထားရင် freeze မလုပ်ဘူး (အသံက ဗီဒီယိုကုန်ပြီးမှ ဆက်ထွက်နေမယ်)။
TikTok/Reels · YouTube · 1:1 / 4:5 = ပို့စ်။ ထုတ်တဲ့ MP4 မှာ သက်ရောက်မယ် (Video tab burn box နဲ့ တစ်ထပ်တည်း)။

Cloud — Firestore

Cloud ချိတ်နေပါတယ်…
ပိတ်ထားရင် ဒီစက်ထဲမှာပဲ သိမ်းမယ်။ ဖွင့်ထားရင် Google sign in ဝင်ထားရင် cloud မှာပါ အလိုအလျောက် သိမ်းမယ် (30 စက္ကန့်တစ်ခါ အများဆုံး)။
Firestore Security Rules (တစ်ခါပဲ ထည့်ရမယ်)
Firebase Console → Firestore Database → Rules မှာ ဒီ rules ကို paste လုပ်ပါ — ကိုယ့် project ကိုယ်ပဲ ဖွင့်/သိမ်း/ဖျက်လို့ရမှာ ဖြစ်အောင်။
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/projects/{projectId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
