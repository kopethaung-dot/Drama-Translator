ဗီဒီယိုကနေ မြန်မာစာတန်းထိုး SRT ထုတ်မယ်

ဗီဒီယို / အသံဖိုင် (သို့) SRT ဖိုင် ထည့်လိုက်ရင် မြန်မာ စာတန်းထိုး (.srt / .vtt) ထုတ်ပေးပါတယ်။ Engine ၄ မျိုး ရွေးလို့ရပါတယ်။

သိမ်းထားတဲ့ ပရောဂျက် ရှိပါတယ် — ။ အဲဒီကနေ ဆက်လုပ်မလား?

၁ — ဖိုင်ရွေးပါ

နှိပ်ပြီး ဖိုင်ရွေးပါ (သို့) ဒီမှာ ဆွဲချလိုက်ပါ
mp4, webm, mov, mp3, wav စတဲ့ ဗီဒီယို / အသံဖိုင် အားလုံး ရပါတယ်
နှိပ်ပြီး .srt / .vtt ဖိုင်ရွေးပါ (သို့) ဒီမှာ ဆွဲချလိုက်ပါ
ရှိပြီးသား စာတန်းကို မြန်မာပြန်ဆိုပေးမယ် — အချိန်တွေ ဒီအတိုင်း ထားမယ်

၂ — ဆက်တင်များ

ဒီကွက်မှာ ရိုက်ထားရင် အပေါ်က ရွေးထားတာထက် ဒါကို အရင်သုံးမယ်။ မော်ဒယ်အမည်ကို AI Studio ရဲ့ model စာရင်းက အတိအကျ ကူးထည့်ပါ။ မရှိတဲ့ မော်ဒယ်ဆိုရင် အလိုအလျောက် မူလ (3.8 Flash) ကို ပြန်သုံးမယ်။
အဆင့်မြင့် ဆက်တင်များ (Pacing၊ batch၊ fallback)
Request တွေကြား စောင့်ချိန် — ၇ စက္ကန့်ဆို 429 (limit) ထိတာ အများကြီး လျော့တယ်။ 0 = မစောင့်ဘူး။
ဘာသာပြန်ပြီးသား စာတန်းတွေကို မှတ်ထားပြီး ပျက်လို့ ပြန်လုပ်ရင် မပို့တော့ဘူး၊ စာသားတူတာကို တစ်ခါပဲ ပို့တယ်။ Model၊ ပုံစံ box၊ Glossary ပြောင်းရင် အလိုအလျောက် အသစ်ပြန်ဘာသာပြန်မယ်။
Key မရှိရင် Google AI Studio မှာ အခမဲ့ ထုတ်ပါ။ Key ကို ဘယ်မှာမှ မသိမ်းဘူး — tab ပိတ်ရင် ပျက်မယ်။
Gemini မုဒ်မှာ အကြောင်းအရာကို Google server သို့ ပို့ရတယ်။ 429 ထိရင် အလိုအလျောက် စောင့်ပြီး ပြန်ကြိုးစားပေးမယ်။
Key မရှိရင် Azure Portal မှာ "Translator" resource (F0 — အခမဲ့) ဖန်တီးပြီး "Keys and Endpoint" က Key နဲ့ Region ကို ထည့်ပါ။ Key ကို မသိမ်းဘူး — tab ပိတ်ရင် ပျက်မယ်။
ဘာသာပြန်ဖို့ စာသားကို Microsoft server သို့ ပို့ရတယ် (အသံကတော့ စက်ထဲမှာပဲ)။ F0 မှာ တစ်လ စာလုံး 2M အခမဲ့။
Key / အကောင့် မလို။ ပထမအကြိမ် မော်ဒယ် (~၁ GB) တစ်ခါ ဒေါင်းရမယ်။ မူရင်းဘာသာစကားကို အတိအကျ ရွေးပါ ("အလိုအလျောက်" ဆို တရုတ်အဖြစ် ယူဆမယ်)။
အားလုံး စက်ထဲမှာပဲ — unlimited။ ဖုန်းမှာ နှေးနိုင်ပြီး အရည်အသွေး Gemini လောက် မမီနိုင်ဘူး။
Oxion AI Dashboard မှာ API Key ဖန်တီးပြီး ထည့်ပါ။ Key ကို ဒီစာမျက်နှာမှာပဲ အသုံးပြုပြီး သိမ်းမထားပါ။ Browser ထဲက API Key ကို အခြားသူတွေ မြင်နိုင်နိုင်တဲ့အတွက် ကိုယ်ပိုင်စက်မှာသာ သုံးပါ။
Oxion AI ဆီ စာသားကို အင်တာနက်မှတစ်ဆင့် ပို့ပြီး မြန်မာဘာသာပြန်မယ်။ Video မုဒ်မှာ အသံဖတ်ခြင်းကို Whisper က စက်ထဲမှာ လုပ်ပြီး စာသားကိုသာ Oxion AI ဆီ ပို့မယ်။
ဘာသာပြန်ပုံစံ (Style) နဲ့ နာမည်မှတ်တမ်း (Glossary) — မလိုရင် ကျော်ပါ
ဒီစာကို Gemini ဘာသာပြန်တိုင်း ထည့်ပေးမယ်၊ ဒီ browser မှာ မှတ်ထားမယ်။ ပြင်ဆင်ရေးထဲမှာ ပြင်ခဲ့တဲ့ စာတန်းတွေကို မူရင်း၊ စက်ပြန်၊ သင်ပြင်တာ အတွဲလိုက် ထုတ်ပေးတာက နမူနာအသစ်တွေ ရေးဖို့ အသုံးဝင်တယ်။
ဒီနာမည်တွေကို ဘာသာပြန်တိုင်း ဒီပုံစံအတိုင်းပဲ သုံးမယ် — အပိုင်းများတဲ့ ဇာတ်လမ်းမှာ နာမည် မလွဲအောင်။ "အလိုအလျောက် ထုတ်မယ်" က Gemini + Key လိုတယ်။
ပထမအကြိမ် မော်ဒယ် ဒေါင်းရမယ် (အင်တာနက် လိုတယ်)။ အသံဖတ်တာ စက်ထဲမှာပဲ — ဖိုင် အပြင် မထွက်ဘူး။
အပိုင်းများစွာ တန်းစီ (Batch)
အပိုင်းတွေ အများကြီး တစ်ခါတည်း ထည့်လို့ရပါတယ်
တစ်ပိုင်းပြီးမှ နောက်တစ်ပိုင်း အလိုအလျောက် ဆက်လုပ်မယ်
အပေါ်က ဆက်တင်တွေကို အပိုင်းအားလုံးအတွက် သုံးမယ်။ လုပ်နေတုန်း tab မပိတ်ပါနဲ့၊ screen ဖွင့်ထားပါ။

ပြင်ဆင်နေပါတယ်…
အသေးစိတ် မှတ်တမ်း (log)
ပြင်စရာစာတန်း မရှိသေးပါဘူး — ဘာသာပြန် tab မှာ အရင် ဘာသာပြန်ပါ၊ ဒါမှမဟုတ် Projects tab က ပရောဂျက် ဖွင့်ပါ။

ပြီးပါပြီ — စာတန်းတွေ အဆင်သင့်ဖြစ်ပါပြီ

ဗီဒီယို ဖွင့်ရင် စာတန်းတွေ အပေါ်မှာ တက်ပြမယ်။
စာတန်းအချိန် လွဲနေရင် ညှိရန် (Sync)
တိကျအောင် ညှိချင်ရင် — စာတန်းအစပိုင်းက တစ်ကြောင်း၊ အဆုံးပိုင်းက တစ်ကြောင်း ရွေးပါ။ စာတန်းအမှတ်ကို ထည့်ပြီး ဗီဒီယိုကို အဲဒီစကားပြောတဲ့နေရာကို ရွှေ့ကာ ⏱ ကိုနှိပ်ပါ။ ညှိမယ်ကို နှိပ်ရင် စာတန်းအားလုံးရဲ့ အချိန်ကို အချိုးကျ ပြန်တွက်ပေးမယ်။

စာတန်းထိုးပြီး ဗီဒီယို ထုတ်မယ်

စာတန်းကို ဗီဒီယိုထဲ တိုက်ရိုက် ထည့်ပြီး ဖိုင်အသစ် ထုတ်မယ်။ ချိန်လိုက်တာနဲ့ အစမ်းပြမှာ ချက်ချင်း ပြောင်းပြမယ်။
နံပါတ်က ဗီဒီယိုအမြင့် 1080 px အပေါ် အခြေခံတဲ့ ဖောင့်ဆိုဒ်ပါ (ဥပမာ 24 = သေးသေး၊ 39 = ပုံမှန်၊ 60 = ကြီး)။ ဒသမ ရိုက်လို့ရတယ် (ဥပမာ 0.5)။ 0 ထည့်ရင် စာတန်း လုံးဝ မမြင်ရတော့ဘူး။ ဗီဒီယိုအရွယ်ကွာရင်လည်း အချိုးကျ ပြောင်းပေးမယ်။
ဗီဒီယို အချိုးအစား (TikTok / YouTube…)
9:16 = TikTok/Reels · 16:9 = YouTube · 1:1 / 4:5 = ပို့စ်။
မှုန်ဝါး = နောက်ခံ blur · အနက်ရောင် = letterbox ဘောင် · Crop = ဘောင်မပါ အပြည့်ဖြတ်။
ကြည်လေ ဖိုင်ကြီးပြီး ကြာလေပဲ။ မူရင်းထက် သေးရင် မူရင်းအရွယ်အတိုင်းပဲ ထုတ်မယ်။
ကိုယ်ပိုင်ဖောင့် / Logo ထည့်ရန်
အခု သုံးနေတာ — Noto Sans Myanmar (မူရင်း)။ ကိုယ်ပိုင်ဖောင့်က ဒီ tab ဖွင့်ထားသရွေ့ပဲ ရမယ်။
Logo မထည့်ရသေးဘူး။ PNG (နောက်ခံ ပွင့်လင်း) ဆို အလှဆုံးပဲ။
သတိ — အချိန်မှန်အတိုင်း ပြန်ဖွင့်ပြီး ထုတ်တာမို့ ဗီဒီယိုရှည်သလောက် ကြာမယ်။ ထုတ်နေတုန်း tab မပိတ်ပါနဲ့။
နောက်ကျနေရင် +၊ စောနေရင် − ထည့်ပါ (ဥပမာ 1.5 = ၁.၅ စက္ကန့် နောက်)။

စာတန်းများ ပြင်ဆင်မယ်

ဒေါင်းမဆွဲခင် စာသားနဲ့ အချိန်တွေ ဒီမှာ ပြင်လို့ရတယ်။ အချိန်ကို စက္ကန့် (65.5) နဲ့ရော 0:01:05.5 နဲ့ရော ရိုက်လို့ရတယ်။
အလိုအလျောက်ခွဲရင် ကန့်သတ်ထက်ရှည်တဲ့ စာတန်းတွေကို "။" "၊" နဲ့ space ကျတဲ့နေရာမှာ ဖြတ်ပြီး အချိန်ကို စာလုံးအရေအတွက်အလိုက် ခွဲပေးတယ်။ တစ်ခုချင်းခွဲချင်ရင် စာတန်းအကွက်ထဲမှာ ခွဲချင်တဲ့နေရာကို နှိပ်ထားပြီး အပေါ်က ✂ ကိုနှိပ်ပါ။

ဗီဒီယို ပြင်ဆင်ရန်

ဗီဒီယို မရှိသေးပါဘူး — ဘာသာပြန် tab မှာ ဗီဒီယို အရင် ဘာသာပြန်ပါ၊ ဒါမှမဟုတ် Projects tab က ပရောဂျက် ဖွင့်ပါ။

🔊 Movie Recap မြန်မာအသံထုတ် (Gemini TTS)

Recap စာသား (script) ကို ဒီမှာ paste လုပ်ပြီး မြန်မာအသံဖိုင် (WAV) ထုတ်ပါ။ စာရှည်ရင် အပိုင်းလေးတွေ အလိုအလျောက် ခွဲပြီး ပြန်ဆက်ပေးမယ်။
Key ကို မသိမ်းဘူး — tab ပိတ်ရင် ပျက်မယ်။ Request တစ်ခုချင်းကြား စောင့်ချိန်ကို ဘာသာပြန် tab ထဲက Gemini "Pacing" နဲ့ တူတူ သုံးမယ် (မူလ ၇ စက္ကန့်)။
ပျက်သွားရင် (429 စတာ) "အသံထုတ်မယ်" ကို ပြန်နှိပ်ပါ — ထုတ်ပြီးသား အပိုင်းတွေ ပြန်မထုတ်တော့ဘူး။ စာသား၊ အသံ၊ လေသံ တစ်ခုခု ပြောင်းရင်တော့ အသစ်ပြန်ထုတ်မယ်။

ပရောဂျက်များ

နာမည်ပေးပြီး သိမ်းထားရင် နောက်မှ ပြန်ဖွင့်ပြီး အချိန်မရွေး ဆက်ပြင်လို့ရတယ်။ ဗီဒီယိုဖိုင်ကိုတော့ သိမ်းမရဘူး — ပြန်ဖွင့်ရင် ဗီဒီယိုဖိုင် ပြန်ရွေးပေးရမယ် (စာတန်းနဲ့ ဗီဒီယို setting တွေကတော့ အကုန် ပြန်ရမယ်)။

ဒီစက်ထဲက ပရောဂျက်များ

Cloud — Firestore

Cloud ချိတ်နေပါတယ်…
Firestore Security Rules (တစ်ခါပဲ ထည့်ရမယ်)
Firebase Console → Firestore Database → Rules မှာ ဒီ rules ကို paste လုပ်ပါ — ကိုယ့် project ကိုယ်ပဲ ဖွင့်/သိမ်း/ဖျက်လို့ရမှာ ဖြစ်အောင်။
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/projects/{projectId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
